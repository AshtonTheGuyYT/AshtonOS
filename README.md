# AshtonOS

A browser-based desktop environment built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser, or serve this folder with any static web server.

## Included apps

- Files, Notes, Text Editor, Calculator
- Calendar with major international and regional holidays
- Browser launcher, Terminal, Image Viewer
- Music synthesizer, System Monitor, Task Manager
- Settings, App Library, Clock and Weather dashboard

## Data

User preferences, notes, files, and calendar events are stored locally in the browser using localStorage. No account or backend is required.

## Keyboard shortcuts

- `Ctrl/Cmd + Space`: app launcher
- `Ctrl/Cmd + S`: save in the editor
- `Alt + Tab`: cycle open windows
- `Escape`: close launcher or menus
